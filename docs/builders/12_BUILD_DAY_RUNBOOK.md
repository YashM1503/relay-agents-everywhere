# Build-Day Runbook

## Rule
Do not build a platform. Build **one proof that implies the platform**.

## Standard 4h15 plan

### T+0 to T+20 — Lock contract
All three:
- freeze demo
- agree frontend/backend JSON
- confirm real vs mocked

### T+20 to T+75 — Independent core build
Builder A:
- static mobile flow
- active session
- camera/mic UI

Builder B:
- state machine
- model call
- tool fixtures
- COUNTERSIGN

Business:
- dataset
- pitch outline
- demo script
- judge story

### T+75 to T+135 — Connect
- UI ↔ backend
- one task through full path
- action proposal
- receipt

### T+135 to T+180 — Multimodal + error
- camera document
- missing-back-card error
- recovery

### T+180 to T+210 — Safety/polish
- confirmation
- cancel
- graceful model failure
- accessibility

### T+210 to T+235 — Freeze
No new features.
Run demo 3 times.

### T+235 to T+255 — Record / show-and-tell prep
- clean demo
- push repo
- README
- submission assets

## Cut in this order
1. second live agent
2. WhatsApp
3. IoT
4. persistent DB
5. watch rules
6. TTS
7. secondary scenario

Never cut:
- environment/context
- user control
- working action
- COUNTERSIGN confirmation
- receipt
