# RELAY — Hackathon Build Packet

## What RELAY is
RELAY is a **phone-first accessibility and action layer**. It lets a person keep interacting with the real world while the phone helps them understand, navigate, complete, and safely execute everyday tasks.

It combines:
- **ACCESSBRIDGE** — help through confusing digital/physical workflows
- **Conversation Relay** — explicit “stay with me” sessions during real interactions
- **Care / Commitment Relay** — remember and follow through
- **Control Tower** — interrupt only when the user actually needs to decide
- **Agent Router** — choose the best available specialist agent
- **COUNTERSIGN** — proof-before-permission for consequential actions
- **IoT/Event Connectors** — optional event-driven context from devices/services

## Core product principle
**Assist the user; do not supervise the user.**

## One-line pitch
> RELAY turns the phone you already carry into an accessibility agent for the world around you — helping you see, understand, and complete everyday tasks while keeping you in control.

## Hackathon thesis
> People should not have to stop a real-world interaction, open a chatbot, and re-explain the situation. RELAY joins the interaction already happening.

## Recommended demo
1. A clerk asks the user to scan a QR code and complete registration.
2. User says: **“RELAY, stay with me.”**
3. RELAY sees/hears the task, opens the workflow, simplifies it, reuses permitted profile information, and asks only unresolved questions.
4. RELAY captures a document with the phone camera.
5. RELAY proposes the final submission.
6. COUNTERSIGN flags sensitive data and asks for explicit confirmation.
7. The workflow completes.
8. RELAY stores the receipt / follow-up.

## Do not build today
- always-on background listening
- universal caregiver monitoring
- medical diagnosis
- financial advice
- universal browser automation
- ten agent integrations
- full IoT platform
- autonomous emergency response
