# Pre-build provenance

## Before the official hackathon build window

The repository initially contains planning material only:

- product specifications
- architecture specifications
- UI/UX concepts
- prompts
- demo-data design
- red-team analysis
- business case
- build runbooks
- testing plans

No finished hackathon application or core runtime was implemented before the official build window.

## During the hackathon

All executable application code, runtime integrations, agent workflows and final demo functionality should be committed during the official build period.

We will preserve Git commit history so the distinction is clear.
